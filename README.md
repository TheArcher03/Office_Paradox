# Office Paradox

A Twofold Productions prototype. You're in a gray office cubicle. Nobody tells you what to do.

**Status:** Stage 1 of the prototype, *The Box*: the cubicle, first-person controls, the rolling chair, and grab / inspect / throw physics.

## Play it
```
npm install
npm run dev      # play in your browser at the printed address
npm run build    # makes one file, dist/index.html, you can open or share
```

## Controls
| Input | Action |
|---|---|
| Mouse | Look around |
| W A S D | Walk, or roll the chair |
| E | Sit / stand |
| Click | Grab · click again to drop |
| Hold click | Wind up a throw, release to let go |
| Hold right-click | Inspect what you're holding |
| Arrow keys | Look (if the mouse won't lock) |
| Esc | Pause |
| ` | Debug: color slider |
